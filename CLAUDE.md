# Notes for Claude working on The Tree of Life

The owner is a writer and songwriter, not a programmer. Explain changes in plain words: what their hand does, what they see on the page.

## The app
- Native iPad app, SwiftUI + PencilKit, iPadOS 17 target. The device is a 6th-generation iPad (2 GB RAM) with a 1st-generation Apple Pencil, so keep things light.
- Project is generated by XcodeGen from `project.yml`. Don't commit an .xcodeproj.
- Source is in `Sources/`, the icon in `Resources/`.
- Builds run on GitHub Actions (`.github/workflows/build.yml`). Every push builds. Without Apple secrets it produces `TreeOfLife.ipa` for Sideloadly; with them it uploads to TestFlight.
- You can't run the app. Keep changes small and compile-safe, and read related files before editing.

## Rules that must never break
- Writing time: the clock runs while the Pencil tip is down with an inking tool (pen, pencil, marker) OR the thumb button is held. Each second counts once. Erasing and lasso don't count on their own. AI activity never adds time.
- Never lose the owner's writing: keep the backup format (`Backup.swift`, `format: "tree-of-life-backup"`) readable, and only add fields, never remove them.
- Keep the spelling "enscribe".

## How we work
- `ROADMAP.md` is the to-do list. Mark items you finish.
- `TESTING.md` gets a checklist for every feature you add: concrete steps on the iPad and what should happen.
- Prefer making feel-settings live-adjustable through `Tuning.swift` (add a `TuningKey`) instead of hard-coding numbers.
